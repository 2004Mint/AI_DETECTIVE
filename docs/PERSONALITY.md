# AI 人格研究所 · 内容与规则说明

5 道趣味题 → 8 种人格档案 → 分享 / 存图。纯前端规则匹配，**不调用任何实时 AI 接口**。

- 页面：`/personality`（首页）、`/personality/quiz`（答题）、`/personality/result`（结果）
- 不注册、不收集姓名手机号；作答只存在本机 `localStorage`（键 `ai-personality:v1`）

---

## 一、文件在哪

| 想改什么 | 改哪个文件 |
| --- | --- |
| 题目、选项、每个选项加什么分 | `src/data/personality/questions.ts` |
| 人格名称、宣言、描述、关键词、台词、主题色 | `src/data/personality/personalities.ts` |
| 匹配 / 并列决胜规则 | `src/data/personality/matching.ts` |
| 页面文案与版式 | `src/views/personality/*.vue`、`src/components/personality/*.vue` |
| 结果图（canvas 导出）的排版 | `src/utils/personalityCard.ts` |

改完跑一次：

```bash
npm run check:personality
```

它会用 **1024 种作答组合**全量验证：八种人格是否都能命中、分布是否过于集中、同一答案结果是否稳定、
并列决胜是否可靠。

## 二、计分与匹配规则

1. 每个选项给 **1～2 个性格**加分：主性格 `+2`，副性格 `+1`（写在 `scores` 里）。
2. 五题累加，取总分最高的性格作为结果。
3. **并列决胜**（按顺序）：
   1. 依次比较第 5、4、3、2、1 题的单项得分，先分出高下的那一题决定胜负；
   2. 五题都一样时，按档案编号顺序（`TYPE-01` 优先）。

这套规则完全确定：同一组答案永远得到同一个人格，与设备、时间、刷新次数无关。

## 三、加题 / 改题

`questions.ts` 里加一条即可，页面、进度条、守卫都会自动跟着变（题数取自 `PERSONALITY_QUESTIONS.length`）：

```ts
{
  id: 'q6',
  index: 6,
  kicker: 'A SMALL CHOICE',
  title: '题目文案',
  options: [
    { id: 'A', label: '选项文案', scores: { creator: 2, explorer: 1 } },
    // …B / C / D
  ],
}
```

注意：

- `index` 必须连续，进度条与「01 / 05」用它；
- 四个选项 `id` 必须是 `A/B/C/D`（自检会报错）；
- 选项最多指向 2 个性格，否则结果会糊。

## 四、结果图与分享

- **分享我的结果**：优先调用系统分享（`navigator.share`），不支持时复制文案到剪贴板；
- **保存结果图**：用 canvas 现画一张 900×1360 的档案图（`src/utils/personalityCard.ts`），
  不依赖截图库；iOS Safari 不支持 `download` 时会打开图片，长按保存即可。

## 五、已知限制

- 作答存在本机，换手机 / 清缓存就没了（现场扫码场景一般不会遇到）；
- 没有后台，改内容 = 改代码 + 重新构建；
- 结果图用的是系统字体，不同设备上字形略有差异。

## 六、结果卡（票根档案）与动效

结果页的卡片是「票根」结构：上半截票头（编号 / 人格名 / 宣言 / 关键词），
中间一条打孔撕票线——**卡片左右两端是真的被挖掉两个半圆**（CSS mask，
缺口位置由撕票线的实际位置动态计算，人格名换行也不会错位），下半截是正文。

动效由 **GSAP** 驱动，只在结果页按需加载（动态 `import()`，单独一个约 28KB gzip 的 chunk，
其他页面不会下载）：

| 效果 | 做法 |
| --- | --- |
| 卡片 3D 抬起 + 淡入 | `gsap.from(card, { y, scale, rotateX })` |
| 人格名逐字浮起 | 名称按字符拆成 `.pl-char`，`stagger: 0.018` |
| 编号「解密」 | 先随机字符再逐位定型（`scramble()`） |
| 撕票线展开 | `scaleX: 0 → 1` |
| 倾向条生长 | `.pl-tend-fill` 依次 `scaleX` |
| 沿边框游走的光带 | `@property --beam-angle` + conic-gradient 遮罩环，GSAP 匀速转 |
| 入场扫光 | `.pl-shine` 斜向高光横扫一次 |
| 星尘上浮 | 14 个 `.pl-spark`，随机延迟循环 |

性能与可访问性：

- 用户系统开启「减少动态效果」时，整套 GSAP 时间线**直接跳过**（内容静态呈现）；
- 常驻动画只动 `transform` / `opacity` / 自定义角度属性，不触发重排；
- 光带用 `@property` 注册角度，支持时平滑旋转，不支持时退化为静态渐变。

想调快慢：改 `PersonalityCard.vue` 里时间线的 `duration` / `stagger`；
想关掉某个效果：删掉对应那段 tween 即可，样式不依赖动画。
